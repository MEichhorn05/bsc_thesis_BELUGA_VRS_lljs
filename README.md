# bsc_thesis_BELUGA_VRS_lljs
The provided code was created within the B. Sc. Thesis with the title "Analyse von Starkwindbändern (Low Level Jets) in der arktischen atmosphärischen Grenzschicht anhand von Fesselballonmessungen in Station Nord (Grönland)".
The code was written in a jupyter notebook using the Python Version 3.12.9.
The following data is used: 

H. Dorff. CARRA reanalysis height-level data at Station Nord for balloon-borne (BELU-
GA) campaign (March, April 2024). Nov. 2025. doi: 10.5281/zenodo.17660389. URL
https://zenodo.org/records/17660389.

H. Dorff, J. Müller, H. Siebert, M. Schäfer, A. Ehrlich, and M. Wendisch. Daily radioson-
de profile measurement data complementing balloon-borne measurements at Villum
Research Station for characterising the Arctic atmospheric boundary layer, 2026a. URL
https://doi.pangaea.de/10.1594/PANGAEA.987053.

H. Dorff. CARRA reanalysis height-level data at Station Nord for balloon-borne (BELU-
GA) campaign (March, April 2024). Nov. 2025. doi: 10.5281/zenodo.17660389. URL
https://zenodo.org/records/17660389.
